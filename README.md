## [![Typing SVG](https://readme-typing-svg.herokuapp.com?font=Fira+Code&pause=1000&color=F7AD51&width=600&lines=Hi%2C+I'm+Muhamad+Sidik+(MyusiZ3);Creative+Technologist+%26+Full-Stack+Developer;Web%2C+Mobile+%26+Interactive+3D%2FAR+Engineering)](https://imycreative.vercel.app/)

Applied Science graduate in **Multimedia Engineering Technology** from **Telkom University** (GPA 3.83/4.00, *Cum Laude*). I build full-stack web and mobile applications, interactive 3D/AR systems, and user-centered interfaces, backed by hands-on experience in enterprise IT operations and technical support.

- **Engineering & Architecture**: Full-stack web and mobile development using **Vue.js, Vite, Flutter (Dart), PostgreSQL, Supabase, and Firebase**.
- **Interactive 3D, AR & Game Systems**: Marker-based and dynamic cloud Augmented Reality, VR simulation, and educational games built with **Unity (C#) and Vuforia Engine**.
- **UI/UX & Operations**: End-to-end interface prototyping in **Figma**, enterprise IT troubleshooting, and software quality assurance (**Black-Box & SUS Usability Testing**).
